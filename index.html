About

Standalone Radar Control, or SRC for short, is completely free, standalone radar control software for ATC, GCI and AIC outside the DCS World environment.

SRC comes as 2 standalone applications, the Client & the Server

Pardon the construction, SRC and its documentation are in alpha.

FAQ

What is this?

A standalone way to control players on a radar scope outside of DCS World, most commonly known as ATC, GCI and AIC.

Do I need DCS World installed, or own any maps?

No, not to control. The client runs on its own. Only whoever hosts the SRC Server runs it next to their DCS server.

Does it use Tacview, DCS-gRPC, MIST or MOOSE?

No. The SRC Server uses its own custom export scripts, written in Lua.

What do I need?

See the client and server requirements.

Do I need SRS?

Yes, only for servers in Advanced simulation or above, where IFF reads transponders through SRS. Without it, tracks stay PENDING. This is NOT required for Arcade.

Installation

  1. Unzip and run Application/Client.exe
  2. In System Connect, click ADD SERVER
  3. Give the server profile a name, enter the server's address, port, your coalition, callsign and optional password, then CREATE
  4. Select the server and click CONNECT

Requirements

  • Windows 10 or 11
  • Support for OpenGL 4.1 or greater
  • Keyboard and mouse
  • Internet

Documentation

Commands

Commands are typed into SYSTEM COMMAND, or anywhere on the scope, and executed by pressing Enter or by middle clicking a track. Middle clicking a track inputs the TID and executes the command.

<TID> is a track number or a callsign. Leave it out to use the selected track.

Implied Commands

Implied commands can be executed without the TID

CommandDescription
/<TID> or / <TID>Switches a data block between LIMITED and FULL
//<TID> or // <TID>Toggles a track's VCI
<1-9> <track>Positions a data block

System Commands

CommandDescription
QF <track>Shows a track's flight data in SYSTEM RESPONSE
BR <track>Shows bearing, range, altitude and aspect from the selected track to another
BR <track> <track>Shows bearing, range, altitude and aspect between two tracks
QR <callsign>Renames the selected track for your whole side
QR <track>`<callsign>Renames a track for your whole side
QR <track>`Resets a track's callsign
  • BR adds the pair to the BRAA LIST. With middle click, the first click inputs one track and the second runs it.
  • Up and Down step through earlier commands, Ctrl+R brings back the last one, Esc clears the line.

Server

Download

About

The server runs on the same PC as your DCS World server feeding surveillance data to controllers.

Installation

  1. Open DCS World/Scripts/MissionScripting.lua in your DCS install folder and comment out the lfs, require and package lines: 
    do
    sanitizeModule('os')
    sanitizeModule('io')
    --sanitizeModule('lfs')
    --_G['require'] = nil
    _G['loadlib'] = nil
    --_G['package'] = nil
end
    DCS updates overwrite this file, so you'll need to do this again after each update
  2. Unzip and run Application/Server.exe
  3. DCS tab: SELECT your DCS server's Saved Games folder, then INSTALL SCRIPTS
  4. NETWORK tab: set Address to 0.0.0.0 and forward the Port (UDP, default 27020)
  5. COALITIONS tab: set an optional password for each side
  6. Click START, then start or restart your DCS server

SRS Server

Only needed for transponders in Advanced simulation or greater. Do these before starting the server

  1. Enable LotATC Transponder Export
  2. Enable Distance Limit
  3. Forward your SRS export server port (UDP, default 10712)

Requirements

  • Windows 10 or 11
  • Runs on the same PC as your DCS World server
  • Port forwarding for controllers to connect
  • SRS, only for transponders in Advanced simulation or greater, see SRS

Documentation

Headless (No GUI)

Setup your instances in the GUI window first. 

Server.exe --headless --instance "My Server Name" --autoupdate
OptionDescription
--headlessRuns in the console with no window context, and starts every instance with Auto Launch Server on
--instance "name"With --headless, starts this instance instead, by name or by its number from --list. Use it more than once for several
--allWith --headless, starts every instance
--autoupdateWith --headless, checks for a new release when on start and restarts with the same options
--listPrints the instances and exits
--verboseAlso logs every network message
--helpPrints the options

While running, type a command into the console and press Enter. An instance is its name or its number from list, and you can leave it out when you only have one.

CommandDescription
helpLists the commands
listInstances and whether they're running
status [instance]The dashboard, with the server, controllers, radar, DCS and mission
clients [instance]Connected controllers
start <instance | all>Starts an instance
stop <instance | all>Stops an instance
restart [instance]Stops an instance, then starts it again
install-scripts [instance]Installs the DCS scripts into Saved Games
fpsUpdate rate and time over the last 5 seconds
profileDisplay stats on the slowest functions
quitStops every instance and exits
  • Ctrl+C or closing the console stops every instance cleanly, the same as quit.
  • Without --autoupdate, a headless server doesn't update itself. Update it from the window, or download the new release.

Simulations

ModeDescription
ArcadeAll aircraft, with its identity known from its DCS coalition. No SRS needed.
AdvancedOnly what the side's radars detect. A contact becomes a track after enough returns, and IFF decides its identity from Mode 4 replies over SRS.
RealismRuns the Advanced settings for now.
CustomCustom toggles from the above simulations

Without SRS, Advanced and above can't interrogate transponders, so tracks stay PENDING.
