# Standalone Radar Control for DCS World

**Website: https://wizxrd.github.io/StandaloneRadarControl/**

## Description

Standalone Radar Control or **SRC** for short, is a completely free, standalone radar control software used for ATC/GCI/AIC outside the DCS World environment.

It's made of two parts, the **Server** which runs alongside your DCS server and the **Client** which controllers use to control.

*SRC is still being worked on, so things will change and there will be bugs.*

## Client

**[Download Client](https://github.com/Wizxrd/StandaloneRadarControl/releases/latest)** (SRCClient zip on the latest release)

### Requirements

- Windows 10 or 11
- Support for OpenGL 4.1 or greater
- Keyboard and mouse
- Internet

## Server

**[Download Server](https://github.com/Wizxrd/StandaloneRadarControl/releases/latest)** (SRCServer zip on the latest release)

### Requirements

- Windows 10 or 11
- Runs on the same PC as your DCS World server
- Port forwarding for controllers to connect
- SRS, only for transponders (IFF) in Advanced or greater

Older versions and release notes are on the [releases page](https://github.com/Wizxrd/StandaloneRadarControl/releases).
