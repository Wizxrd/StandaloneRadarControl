# Standalone Radar Control for DCS World

**Website: https://wizxrd.github.io/StandaloneRadarControl/**

## Description

Standalone Radar Control or **SRC** for short, is a completely free, standalone radar control software used for ATC/GCI/AIC outside the DCS World environment.

It's made of two parts, the **Server** which runs alongside your DCS server and the **Client** which controllers use to control.

*Pardon the dust, SRC & its Documentation is in alpha, so things will change and there will be bugs.*
